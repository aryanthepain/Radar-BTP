## Executive Summary

Phase 1.1 integrates the real-world **RadDet (ICASSP 2025)** radar spectrum detection dataset into the project repository. It introduces wideband spectrum sensing and automatic signal recognition (ASR) to complement our existing 77 GHz FMCW automotive radar simulation.

Crucially, this phase adheres to two core constraints:
1. **Ultra-lean local footprint**: Using a curated micro-slice (~50–100 samples) in `data/raddet_sample/` to test data loaders, bounding box parsers, and visualizers locally without downloading tens of gigabytes.
2. **100% Preservation**: Leaving all existing synthetic radar simulation (`src/sim/`), classical DSP (`src/dsp/`), and Range-Doppler CNN detectors (`src/models/radar_detector_cnn.py`, `01_` and `02_` notebooks) completely untouched.

Phase 1.1 delivers a modular `src/raddet/` package, a deterministic test suite `tests/test_raddet.py`, and a self-contained Kaggle walkthrough notebook (`03_raddet_spectrum_detection_kaggle.ipynb`) executing a limited-slice training run on Kaggle GPU.

## 1. RadDet Dataset Technical Deep Dive (ICASSP 2025)

### Paper Summary
- **Title**: *RadDet: A Wideband Dataset for Real-Time Radar Spectrum Detection* (IEEE ICASSP 2025, Hyderabad, India)
- **Authors**: Zi Huang, Simon Denman, Akila Pemasiri, Terrence Martin, Clinton Fookes (QUT & Revolution Aerospace)
- **Problem**: Real-time detection and classification of complex radar waveforms across a 500 MHz wideband RF spectrum in degraded SNR environments (-20 dB to +20 dB).

### Signal Representations & Parameters
- Signals are generated from 1 million complex baseband I/Q samples ($\vec{x}_i + j\vec{x}_q$) across 500 MHz over a 2 ms time horizon.
- Converted to **max-hold spectrograms** via STFT without window bias:
  $$\text{dim}(t) = \frac{N - N_{\text{overlap}}}{N_{\text{pool}}(N_{\text{seg}} - N_{\text{overlap}})}, \quad \text{dim}(f) = N_{\text{nfft}}$$
- 11 radar classes:
  - Phase-coded & pulsed: `0: Rect`, `1: Barker`, `2: Frank`, `3: P1`, `4: P2`, `5: P3`, `6: P4`, `7: Px`, `8: ZadoffChu`
  - Frequency modulated: `9: LFM`, `10: FMCW`

### Dataset Variants & Sizes
| Variant | Dimensions | Temporal / Freq Res | Archive Size (Approx) | Structure |
| :--- | :--- | :--- | :--- | :--- |
| **RadDet-9T-128** (Selected) | $128 \times 128$ | $15.6\,\mu\text{s}, 3.91\,\text{MHz}$ | ~0.5 GB | Single `.tar` archive (`raddet40k128hw009tv2.tar`) |
| **RadDet-1T-128** | $128 \times 128$ | $15.6\,\mu\text{s}, 3.91\,\text{MHz}$ | ~0.5 GB | Single `.tar` archive (`raddet40k128hw001tv2.tar`) |
| **RadDet-9T-256** | $256 \times 256$ | $7.81\,\mu\text{s}, 1.95\,\text{MHz}$ | ~2.5 GB | Single `.tar` archive |
| **RadDet-9T-512** | $512 \times 512$ | $3.91\,\mu\text{s}, 0.98\,\text{MHz}$ | ~12.0 GB | 4 split `.tar.part-*` files |

### Annotation Schema (YOLO Format)
Each spectrogram `.png` is accompanied by a matching `.txt` file with lines formatted as:
```text
<class_id> <x_center> <y_center> <width> <height>
```
where all coordinate values are floats normalized to $[0, 1]$.
- $x$: Time axis (normalized)
- $y$: Frequency axis (normalized)
- $w, h$: Bounding box width (dwell time) and height (signal bandwidth)

## 2. Minimal Local Footprint Architecture

### Micro-Slice Directory Layout (`data/raddet_sample/`)
```
data/raddet_sample/
├── data.yaml
├── images/
│   ├── train/  (40 sample spectrograms, 128x128 PNG)
│   ├── val/    (15 sample spectrograms, 128x128 PNG)
│   └── test/   (5 sample spectrograms, 128x128 PNG)
└── labels/
    ├── train/  (40 corresponding YOLO .txt labels)
    ├── val/    (15 corresponding YOLO .txt labels)
    └── test/   (5 corresponding YOLO .txt labels)
```

### Self-Contained Sample Generator (`scripts/fetch_raddet_sample.py`)
To make the repository fully self-reliant and immediately testable on any developer clone without requiring Kaggle API tokens:
1. The script checks if local `data/raddet_sample/` already exists.
2. If absent and a local Kaggle tarball is present, it extracts 60 sample frames.
3. If absent and no tarball is found, it deterministically synthesizes 60 valid max-hold spectrograms with realistic pulse and chirp signatures and proper YOLO bounding-box labels, guaranteeing that `tests/test_raddet.py` will pass immediately.

## 3. Dedicated Package Architecture (`src/raddet/`)

```
src/raddet/
├── __init__.py          # Public exports
├── config.py            # RADDET_CLASSES, color palettes, resolution configs
├── dataset.py           # RadDetDataset (PyTorch Dataset), bbox denormalization, batch collator
└── visualize.py         # plot_spectrogram_detections() with GT & prediction overlays
```

### Key Functional Specifications
- **`src/raddet/config.py`**:
  ```python
  RADDET_CLASSES = {
      0: "Rect", 1: "Barker", 2: "Frank", 3: "P1", 4: "P2",
      5: "P3", 6: "P4", 7: "Px", 8: "ZadoffChu", 9: "LFM", 10: "FMCW"
  }
  ```
- **`src/raddet/dataset.py`**:
  - `load_yolo_annotations(txt_path)`: Parses lines into `List[Dict[str, float]]`.
  - `denormalize_boxes(boxes, width, height)`: Converts `[x_c, y_c, w, h]` into pixel coordinates `[x1, y1, x2, y2]`.
  - `RadDetDataset(root_dir, split='train', transform=None)`: Standard PyTorch `Dataset` yielding `(image_tensor, target_dict)`.
- **`src/raddet/visualize.py`**:
  - `plot_raddet_sample(image, targets, class_names=None, title=None)`: Publication-grade Matplotlib figure with dark theme, showing bounding boxes with label tags and confidence scores.

## 4. Kaggle Walkthrough Notebook Architecture (`03_raddet_spectrum_detection_kaggle.ipynb`)

### Target Execution Environment
- Platform: Kaggle Notebook with GPU acceleration (Tesla P100 or T4 x2)
- Attached Dataset: `abcxyzi/raddet-icassp-2025`
- Working Directory: `/kaggle/working/`

### Notebook Section Outline
1. **Title & Problem Context**:
   - Header with Mermaid architecture flowchart depicting RF front-end, STFT max-hold compression, and YOLO detector.
   - Theoretical overview of Wideband Spectrum Sensing in Electronic Warfare vs 77 GHz Automotive FMCW.
2. **Dataset Setup & Auto-Extraction**:
   - Resolves Kaggle dataset input path: `/kaggle/input/raddet-icassp-2025/`.
   - Locates and extracts `raddet40k128hw009tv2.tar` into `/kaggle/working/data/raddet_subset/`.
   - Subsets the dataset to 1,500 train images and 500 val images for fast Phase 1.1 demonstration.
   - Generates working `data.yaml`.
3. **Exploratory Data Analysis & Spectrogram Visualization**:
   - Plots 4 representative spectrogram frames (Rect, LFM, FMCW, Polyphase codes) with ground-truth bounding box overlays.
   - Computes class frequency histogram across the subset.
4. **Ultralytics YOLO Model Initialization & Training**:
   - Instantiates `YOLO('yolov8n.yaml')` (or `yolov8n.pt`).
   - Runs 15-epoch training loop with AdamW optimizer, warmup, and data augmentation (mixup, mosaic).
5. **Quantitative Validation & Metric Curves**:
   - Plots Training Loss curves (box loss, cls loss, dfl loss).
   - Reports validation `mAP50`, `mAP50:95`, precision, and recall.
6. **Inference Showcase & Detection Visualizations**:
   - Runs model on unseen test frames.
   - Renders 4-panel figure comparing Ground Truth bounding boxes vs Model Predictions with confidence scores.
7. **Academic Discussion & Transition to Phase 1.2**:
   - Analysis of detection performance across modulation classes.
   - Outline of Phase 1.2: 20,000-frame full run, $256^2$ / $512^2$ resolution, multi-SNR breakdown.

## 5. Deterministic Verification & CI Integration

### Test Coverage (`tests/test_raddet.py`)
1. `test_class_mapping()`: Confirms all 11 classes exist and map correctly.
2. `test_bounding_box_normalization()`: Confirms forward and inverse coordinate transforms round-trip within $10^{-5}$ tolerance.
3. `test_dataset_loading()`: Tests loading from `data/raddet_sample/`, verifying image shapes (`(1, 128, 128)` or `(3, 128, 128)`) and label validity.
4. `test_visualizer_smoke()`: Confirms `plot_raddet_sample()` generates a Matplotlib figure without errors or warnings.
5. `test_pytorch_forward_pass()`: Validates that a batch of RadDet spectrogram tensors propagates cleanly through a PyTorch Conv2d block.

All tests will run deterministically within `pwsh -File ./scripts/verify.ps1`.
