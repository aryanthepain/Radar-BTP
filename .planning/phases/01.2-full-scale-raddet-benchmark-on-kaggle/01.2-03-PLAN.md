<action>
Enhance `scripts/push_kaggle_kernel.py` to support post-execution management and artifact retrieval:
1. Implement `pull_kernel_outputs(kernel_id: str, output_dir: Path) -> Path`:
   - Validate that `kernel_id` matches the format `username/slug`.
   - Ensure `output_dir.mkdir(parents=True, exist_ok=True)`.
   - Execute `subprocess.run(["kaggle", "kernels", "output", kernel_id, "-p", str(output_dir)], capture_output=True, text=True, check=True)`.
   - Log downloaded files and return `output_dir`.
   - Catch `subprocess.CalledProcessError` and print informative error diagnostics.
2. Implement `get_kernel_status(kernel_id: str) -> str`:
   - Execute `subprocess.run(["kaggle", "kernels", "status", kernel_id], capture_output=True, text=True, check=True)`.
   - Parse and return the status string (e.g., `running`, `complete`, `error`).
3. Extend CLI arguments in `main()`:
   - Add `--pull` flag (action="store_true", help="Download output files from Kaggle kernel").
   - Add `--status` flag (action="store_true", help="Check execution status of Kaggle kernel").
   - Add `--output-dir` (type=Path, default=Path("data/benchmark_results/s128"), help="Destination directory for pulled outputs").
4. Wire workflow logic in `main()`:
   - If `--status` is supplied: query and print kernel status, then exit.
   - If `--pull` is supplied: download outputs to `--output-dir`, log retrieved files, then exit.
   - If `--push` is supplied: stage metadata and execute push as before.
</action>
