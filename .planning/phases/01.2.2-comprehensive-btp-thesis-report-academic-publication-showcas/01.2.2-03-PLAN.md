<objective>
Transform the GitHub Pages presentation portal (`docs/`) into a formal, publication-grade academic paper reading experience. 

Implement Wave 0 deterministic test suite `tests/test_academic_website.py`, overhaul `docs/styles.css` with a responsive two-column academic layout, serif/sans-serif typography pairing, and advisor defense callout cards, vendor offline KaTeX libraries in `docs/assets/vendor/katex/`, and refactor `docs/app.js` with auto-render math integration, sticky Chapter 1–7 scroll-spy navigation, interactive IEEE citation tooltips, and collapsible code drawers.
</objective>

<threat_model>
ASVS Level 1 Threat Analysis:

- **T-01.2.2-03-01 (Responsive Layout Breakage & Mobile Usability / CWE-1027)**: A rigid two-column desktop layout can overflow viewport boundaries, cause horizontal scrollbars, and render text unreadable on tablets (<900px) and smartphones (<600px).
  - _Mitigation_: Implement a CSS grid/flexbox architecture with strict `@media` breakpoints that seamlessly collapse the two-column grid into a single readable column below 992px width, while wrapping math containers in `overflow-x: auto`.
- **T-01.2.2-03-02 (External Network Dependency Failure / Offline KaTeX Failure / CWE-404)**: Relying on CDN links for KaTeX math and fonts results in raw unrendered LaTeX markup (`$$...$$`) when viewed offline or behind institutional proxies.
  - _Mitigation_: Vendor `katex.min.js`, `katex.min.css`, and `auto-render.min.js` directly inside `docs/assets/vendor/katex/`, validating local script loading in `tests/test_academic_website.py`.
- **T-01.2.2-03-03 (Navigation Desynchronization & Broken Section Anchors / CWE-398)**: Scroll-spy failing to highlight active chapters, or anchor links failing due to missing DOM element IDs.
  - _Mitigation_: Test all chapter anchor IDs (`ch1-intro`, `ch2-physics`, `ch3-dsp-audit`, `ch4-methodology`, `ch5-benchmarks`, `ch6-timeline`, `ch7-conclusion`, `references`) programmatically in `tests/test_academic_website.py`.
</threat_model>
