# Phase 01.2.1: Interactive Research Showcase & Thesis Presentation Website - Context

**Gathered:** 2026-11-03
**Status:** Ready for planning

<domain>
## Phase Boundary

Deliver a lightweight, clean, zero-build, responsive presentation website in `docs/` for the supervising professor. The website synthesizes all three notebooks (`01_radar_classical_dsp.ipynb`, `02_radar_deep_learning_detection.ipynb`, `03_raddet_spectrum_detection_kaggle.ipynb`), illustrating the conceptual, mathematical, algorithmic, and empirical progression from analytical toy models (zero data) to synthetic FMCW radar simulation (synthetic data) to real-world RadDet ICASSP 2025 benchmark on Kaggle (real data from paper). The website incorporates static pre-rendered SVG/PNG diagrams, Prism.js syntax-highlighted code snippets, interactive image lightboxes, immediate plot-level inferences, a 7-metric master comparison table, and concise conclusion bullets.

</domain>

<decisions>
## Implementation Decisions

### Tech Stack & Delivery Mechanism
- **D-01:** Zero-build standalone static site (Vanilla HTML5, modern responsive CSS with flex/grid, lightweight vanilla JS). No Node.js build step or runtime server required. Double-clickable offline in any browser and ready for GitHub Pages hosting. — **Reversibility:** reversible
- **D-02:** Project structure stored in root `docs/` directory (`docs/index.html`, `docs/styles.css`, `docs/app.js`, `docs/assets/`). This enables direct deployment via GitHub Pages (`Settings -> Pages -> Deploy from /docs`) while keeping the repo root clean. — **Reversibility:** reversible
- **D-03:** Visual Theme: Fixed Dark Cyber-Radar aesthetic (`#0a0e17` dark background, `#0f172a` cards, `#1e293b` borders, neon cyan `#00f0ff` and amber `#f59e0b` accents, high-contrast typography) to maintain visual continuity with all existing matplotlib figures in the notebooks. — **Reversibility:** reversible

### Information Architecture & Navigation
- **D-04:** Single-page longform scroll with sticky sidebar navigation (smooth scroll spy, section indicators, back-to-top button). — **Reversibility:** reversible
- **D-05:** Step-by-step sequential timeline diagram near the top showing the 3-stage evolution:
  - *Stage 1: Zero / Analytical Point Targets (Notebook 01)* — Pure mathematical FMCW chirp physics, deterministic DSP, no clutter/noise realism.
  - *Stage 2: Synthetic FMCW Simulation (Notebook 02)* — Micro-Doppler kinematics, ground clutter, thermal noise, CNN heatmap/box regressor, but limited by simulation domain gap.
  - *Stage 3: Real-World RadDet Benchmark (Notebook 03)* — 20,000 automotive radar spectrogram frames, YOLOv9/v8 real-time detection, multi-SNR evaluation (-20 dB to +20 dB). — **Reversibility:** reversible
- **D-06:** Standardized 5-part section block for each notebook:
  1. *Objective & Architectural Role*
  2. *Static Architecture Flowchart (pre-rendered SVG)*
  3. *Key Code Snippets (with line numbers, syntax highlighting, copy button)*
  4. *Primary Plots & Spectra with immediate contextual inferences side-by-side or captioned*
  5. *Key Inferences, Limitations, and Final Words for the Professor*. — **Reversibility:** reversible

### Visuals & Diagram Rendering
- **D-07:** Static pre-rendered SVG/PNG diagrams stored in `docs/assets/diagrams/` — guaranteed 100% offline rendering without CDN failure risks or mermaid JS runtime lag. — **Reversibility:** reversible
- **D-08:** Syntax highlighting via Prism.js (OneDark / Tomorrow theme) with Python / PyTorch keywords, line numbers, and a 1-click Copy button. — **Reversibility:** reversible
- **D-09:** Interactive modal / lightbox popup — clicking any spectrogram or detection plot opens a full-screen zoomed view with analytical captions. — **Reversibility:** reversible

### Notebook Results, Asset Extraction & Synthesis
- **D-10:** Automated asset export script `scripts/export_showcase_assets.py` that programmatically extracts and saves high-resolution plots, spectrograms, and diagrams from notebooks/runs directly into `docs/assets/`. — **Reversibility:** reversible
- **D-11:** Comprehensive 7-metric master comparison table contrasting the 3 notebooks across:
  1. *Data Source & Fidelity*
  2. *Physical Sensor Model & Frequency (77 GHz FMCW)*
  3. *Target Complexity & Modulations*
  4. *Detection Paradigm (Classical CFAR/MUSIC vs Multi-task CNN vs YOLOv9)*
  5. *Operational Latency & FPS*
  6. *Robustness to Clutter & Multi-path*
  7. *Key Engineering Limitations & Generalization*. — **Reversibility:** reversible
- **D-12:** Professor Takeaways Section: Concise bullet list of academic conclusions and key findings. — **Reversibility:** reversible

### the agent's Discretion
- Asset export script design: Script will parse notebooks or invoke lightweight headless generation for any missing high-res figures to ensure `docs/assets/` is self-contained.
- Responsive breakpoints: Mobile and tablet breakpoint layout rules for the sidebar and comparison table.

</decisions>
