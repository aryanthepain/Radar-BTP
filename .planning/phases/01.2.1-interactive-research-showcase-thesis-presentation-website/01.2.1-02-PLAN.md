<threat_model>
ASVS Level 1 Threat Analysis:

- **T-01.2.1-03 (DOM-Based Cross-Site Scripting / CWE-79)**: Dynamic DOM manipulation in `docs/app.js` (such as populating the lightbox modal or copy button feedback) could expose XSS vulnerabilities if untrusted input is interpolated into `innerHTML`.
  - _Mitigation_: Use strictly safe DOM manipulation methods (`element.textContent`, `element.setAttribute()`, `element.classList.toggle()`) and static string references. Avoid dynamic `innerHTML` evaluation.
- **T-01.2.1-04 (External Resource Hijacking & Offline Failure / CWE-829)**: Referencing external CDN fonts or scripts (e.g., Google Fonts, cdnjs, unpkg) causes silent rendering breakage when viewed offline via `file:///` and introduces supply chain security risks.
  - _Mitigation_: Use system font stacks (`-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Consolas`, `monospace`). Ensure all script, style, and image tags point strictly to local relative paths (`./styles.css`, `./app.js`, `./assets/...`). Zero external CDN requests.
</threat_model>

<action>
Create `docs/app.js` using pure vanilla modern JavaScript without external dependencies:
1. `initScrollSpy()`:
   - Uses `IntersectionObserver` with `rootMargin: "-20% 0px -70% 0px"` targeting all major section elements (`#overview`, `#timeline`, `#notebook-01`, `#notebook-02`, `#notebook-03`, `#comparison`, `#conclusions`).
   - When a section intersects, updates `.toc-link` classes, adding `.active` to the corresponding navigation link and removing from others.
2. `initLightbox()`:
   - Selects `#lightbox-modal`, `#lightbox-img`, `#lightbox-caption`, and `#lightbox-close`.
   - Attaches click listeners to all elements matching `img.zoomable, .flowchart-container img, .plot-card img`.
   - On click: sets modal image `src` to clicked target `src`, extracts caption from `alt` or parent `.plot-card figcaption`, sets modal `display: flex`, and prevents body scroll (`overflow: hidden`).
   - Close triggers: Click on `#lightbox-close`, click on background overlay, or `ESC` keyboard event. Restores body scrolling.
   - Prevents XSS (T-01.2.1-03) by using `textContent` for captions.
3. `initCodeCopy()`:
   - Finds all `.code-block-header .copy-btn`.
   - On click: finds sibling or adjacent `code` element, extracts text, calls `navigator.clipboard.writeText(codeText)` (with fallback to `document.execCommand('copy')`).
   - Updates button text to "Copied!" with cyan highlight class for 2000 ms, then reverts to "Copy".
4. `initBackToTop()`:
   - Listens to window `scroll` with passive listener.
   - Adds `.visible` class to `#back-to-top` when `window.scrollY > 400`, removes when $< 400$.
   - On click: calls `window.scrollTo({ top: 0, behavior: 'smooth' })`.
5. `initMobileDrawer()`:
   - Attaches click listener to `#nav-toggle` hamburger button.
   - Toggles `.open` class on `.sidebar` and `.nav-backdrop`.
   - Closes drawer when any `.toc-link` is clicked on mobile.
6. DOMContentLoaded event listener initializing all modules safely.
</action>
