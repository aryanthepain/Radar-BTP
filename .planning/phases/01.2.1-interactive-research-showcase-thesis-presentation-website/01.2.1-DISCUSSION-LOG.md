## Tech Stack & Delivery Mechanism

| Option | Description | Selected |
|--------|-------------|----------|
| Zero-build standalone static site | Vanilla HTML5, modern CSS, lightweight JS — double-clickable offline & 100% GitHub Pages ready with zero npm dependencies | ✓ |
| Vite + React single-page app | Richer component state and animations, but requires Node.js / build step to view locally | |
| Streamlit / Python dashboard | Pure Python app, but requires an active Python server running on localhost | |

**User's choice:** Zero-build standalone static site
**Notes:** Placed directly in root `docs/` folder for native GitHub Pages compatibility and offline double-click viewing by the professor.
