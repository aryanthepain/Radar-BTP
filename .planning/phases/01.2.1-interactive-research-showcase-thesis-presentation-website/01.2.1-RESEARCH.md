## 1. Executive Summary & Problem Formulation

### 1.1 Academic Motivation
The Bachelor Thesis Project (BTP) spans three progressive research milestones:
1. **[01_radar_classical_dsp.ipynb](file:///D:/projects/BTP/01_radar_classical_dsp.ipynb)**: Closed-form FMCW radar signal processing physics, deterministic spectral estimation (Range/Doppler FFT, MTI, 2D CA-CFAR), array spatial super-resolution (MUSIC AoA), and pedestrian micro-Doppler gait STFT kinematics.
2. **[02_radar_deep_learning_detection.ipynb](file:///D:/projects/BTP/02_radar_deep_learning_detection.ipynb)**: Anchor-free multi-task convolutional radar perception (`RadarObjectDetectorCNN`) trained on synthetic Range-Doppler heatmaps with Gaussian keypoint splatting and smooth bounding box regression.
3. **[03_raddet_spectrum_detection_kaggle.ipynb](file:///D:/projects/BTP/03_raddet_spectrum_detection_kaggle.ipynb)**: Real-world benchmark on 20,000 automotive radar spectrogram frames from the ICASSP 2025 RadDet dataset, demonstrating line-rate detection ($892.9\text{ FPS}$) and multi-SNR degradation modeling ($-20\text{ dB}$ to $+20\text{ dB}$).

While each individual notebook is exhaustive, presenting them disjointedly to the supervising professor obscures the overarching **pedagogical narrative**:
> **Analytical Toy Baseline** *(zero data, pure deterministic mathematics)* $\longrightarrow$ **Synthetic FMCW Simulation** *(synthetic data, CNN multi-task perception, sim-to-real gap)* $\longrightarrow$ **Real-World RadDet Benchmark** *(real data from paper, line-rate YOLOv9-C detection, 40 dB dynamic SNR sweep)*.

### 1.2 Architectural Constraints (Decisions D-01 through D-12)
To provide the thesis advisor with an effortless, distraction-free viewing experience, Phase 01.2.1 establishes a **zero-build standalone presentation website** housed in `docs/`:
- **Zero Node.js / Zero Server**: Pure Vanilla HTML5, modern CSS3 (Flexbox/Grid), and lightweight Vanilla JS. Double-clickable locally via `file:///` in any browser and instantly deployable via GitHub Pages (`docs/` source).
- **Dark Cyber-Radar Aesthetic**: Consistent visual language matching the notebook matplotlib figures (`#0a0e17` deep canvas, `#0f172a` cards, `#1e293b` borders, neon cyan `#00f0ff` and amber `#f59e0b` accents).
- **100% Offline Resilience**: Pre-rendered SVGs and extracted PNG figures stored directly on disk in `docs/assets/`. Zero external CDN runtime dependencies (no runtime Mermaid JS, no unpkg/cdnjs dependencies). Vendored offline Prism.js for syntax highlighting.
- **Immediate Contextual Inferences**: Every spectrum, plot, and flowchart is paired with immediate physical, mathematical, and algorithmic explanations, culminating in concise professor takeaways and a 7-metric master comparison table.

#### Core Innovative Code Snippets:
1. **Decoupled Multi-Task CNN Architecture**:
   ```python
   class RadarObjectDetectorCNN(nn.Module):
       def __init__(self, in_channels=1, num_classes=4, base_filters=24):
           super().__init__()
           self.stem = nn.Sequential(
               ConvBNReLU(in_channels, base_filters, stride=1),
               ResidualBlock(base_filters, base_filters * 2, stride=2),
               ResidualBlock(base_filters * 2, base_filters * 4, stride=2)
           )
           # Decoupled Classification & Bounding Box Regression Heads
           self.heatmap_head = nn.Sequential(
               nn.Conv2d(base_filters * 4, base_filters * 2, 3, padding=1),
               nn.ReLU(inplace=True),
               nn.Conv2d(base_filters * 2, num_classes, 1) # Sigmoid Heatmap
           )
           self.box_head = nn.Sequential(
               nn.Conv2d(base_filters * 4, base_filters * 2, 3, padding=1),
               nn.ReLU(inplace=True),
               nn.Conv2d(base_filters * 2, 4, 1)           # [dx, dy, w, h]
           )
   ```

## 7. Professor Conclusions & Academic Findings (D-12)

The website culminates in six high-impact takeaways structured specifically for the thesis committee:

1. **First-Principles Analytical Rigor**:
   Deterministic radar signal processing (Range/Doppler FFT, 2D CFAR, MUSIC) is mathematically indispensable for understanding radar physics, frequency-to-distance mapping ($R = \frac{c f_b T_c}{2 B}$), and velocity phase progression. However, classical methods cannot perform semantic object classification.
2. **The Multi-Task Deep Learning Paradigm**:
   Transitioning from heuristic detection (CFAR) to deep learning (`RadarObjectDetectorCNN`) unifies detection and semantic classification into a single forward pass, eliminating brittle threshold tuning ($P_{fa}$) while maintaining sub-bin bounding accuracy.
3. **The Simulation-to-Reality Domain Gap**:
   While synthetic FMCW simulators permit rapid architectural prototyping and controlled micro-Doppler modeling, they inherently fail to capture complex electromagnetic scattering, multipath reflections, and RF phase noise.
4. **Line-Rate Cognitive EW on Real Spectrum**:
   Evaluating Ultralytics YOLOv9-C on the 20,000-frame RadDet ICASSP 2025 dataset proves that modern object detection backbones can process wideband radar spectrograms at **$892.9\text{ FPS}$ ($1.12\text{ ms}$)**, comfortably exceeding real-time automotive and cognitive EW latency budgets.
5. **Empirical Noise Breakdown Threshold**:
   The multi-SNR sweep demonstrates that radar perception performance remains stable ($>24\%\text{ mAP50}$) down to $+4\text{ dB}$ SNR, after which sub-zero Rayleigh noise submerges weak radar chirps, causing sharp performance degradation matching ICASSP 2025 Fig. 3(c).
6. **Unified Perception Architecture**:
   The research demonstrates that radar perception can ingest data at raw ADC cube, Range-Doppler tensor, or spectrogram levels without architectural rewrites, establishing a modular blueprint for future master/doctoral extensions.
